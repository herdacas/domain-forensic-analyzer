    Domain risk

      Analyst OPSEC

      Analyst IPs, hostname and username are masked. Public addresses use the RFC 5737 documentation ranges.

      What the VPN changes

      Same target, four network setups. The target only ever sees the external IP. On Linux the tool finds the tunnel interface of the internet route; on Windows it can only check the reverse DNS of the exit IP.

      JSON report

      Every scan writes reports/<id>_<domain>.json. This is the result block for the selected scan. Expand a key to look inside.

      Run it yourself

      No API keys needed for a first scan. Active probes come from your IP, so read the VPN section of the README first if that matters for your target.

      git clone https://github.com/herdacas/domain-forensic-analyzer.git
cd domain-forensic-analyzer
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python3 run.py example.com
